# 🌞 Piscina Solar — Projeto Integrador CEP 2026

> **É possível aquecer a piscina da escola com energia solar?**  
> Uma análise científica e tecnológica entre sistemas térmicos e fotovoltaicos.

## 📋 Sobre o Projeto

Desenvolvido para o 3º Trimestre do CEP, este projeto integra:
- **Programação**: Site educacional, interativo e 100% acessível
- **Tecnociência**: Ondas eletromagnéticas, corpo negro e efeito fotoelétrico
- **Robótica**: Sensores e automação aplicados à eficiência energética

## ✨ Funcionalidades

- 📊 **Análise Comparativa**: Térmico vs Fotovoltaico com dados reais
- 🧮 **Calculadora Interativa**: Dimensionamento personalizado de energia
- 🔬 **3 Simuladores Físicos**: Corpo Negro, Efeito Fotoelétrico e Perda Térmica
- 🤖 **Maquete Virtual**: Diagrama interativo do sistema de automação
- ♿ **Acessibilidade Total**: VLibras, alto contraste, fonte para dislexia, navegação por teclado (WCAG 2.1 AA)
