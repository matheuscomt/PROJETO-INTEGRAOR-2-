## 📋 Sobre o Projeto

Este projeto foi desenvolvido como parte do **Projeto Integrador do 3º Trimestre** do CEP (Centro de Ensino Profissionalizante), integrando conhecimentos de:

- **Programação**: Desenvolvimento web com HTML5, CSS3 e JavaScript
- **Tecnociência**: Física moderna (ondas eletromagnéticas, corpo negro, efeito fotoelétrico)
- **Robótica**: Sensores e automação

### 🎯 Objetivo

Investigar cientificamente a viabilidade de aquecer a piscina da escola utilizando energia solar, comparando duas tecnologias distintas:

1. **Sistema Térmico**: Conversão direta de radiação solar em calor
2. **Sistema Fotovoltaico**: Conversão de radiação solar em eletricidade

## ✨ Funcionalidades

### 📊 Análise Comparativa Completa
- Comparação detalhada entre sistemas térmicos e fotovoltaicos
- Vantagens, limitações e casos de uso de cada tecnologia
- Tabela comparativa com métricas técnicas

### 🧮 Calculadora Interativa
- Dimensionamento personalizado de sistemas
- Cálculo de energia necessária para aquecimento
- Estimativa de custos e economia anual
- Consideração de perdas térmicas e eficiência

### 🔬 Simuladores Físicos
1. **Simulador de Corpo Negro**: Visualize como a temperatura afeta a radiação emitida
2. **Simulador do Efeito Fotoelétrico**: Teste diferentes frequências de luz
3. **Simulador de Perda Térmica**: Veja o impacto da capa térmica na piscina

### 🤖 Integração com Robótica
- Diagrama da maquete com sensores
- Explicação dos componentes utilizados
- Benefícios educacionais da prototipagem
